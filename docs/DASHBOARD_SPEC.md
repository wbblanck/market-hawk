# Full dashboard target
1. Command Center: weekly slate, spread/total state, benchmark coverage, best same-contract quote, predictions, quality flags.
2. Market Explorer: synchronized book/contract timeline, line/odds movement, quote age, dispersion and reversals.
3. Opportunity Lab: book/contract, odds, predicted CLV distribution, P(positive CLV), fair probability, net EV, execution risk.
4. Model Intelligence: ATS/game/CLV model versions, baselines and disagreements.
5. Execution Lab: bet-now-vs-wait, fees, slippage, latency, fill and partial-fill scenarios.
6. CLV Analytics: realized/predicted CLV by season, market, book, timing and line bucket.
7. Game Lab: expected margin/total and calibrated distributions, isolated from CLV labels.
8. Data Health: provider history, refresh, latency, missingness, schema errors.
9. Research Lab: preregistration, experiments, ablations and negative results.
10. MCP & Integrations: server health, tools, resources, permissions and audit logs.
All values need source timestamp, model version and quality flag. Do not show an EV+ badge without validated probability, executable quote and costs.
